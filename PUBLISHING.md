# Publishing

The canonical plugin ID is `quest.entropy.zrammonitor`. It must not change after public release because Plasma uses it as the installation and configuration identity.

## Release preparation

1. Update `metadata.json` and `CHANGELOG.md` with the same semantic version.
2. Run `make format`, `make check`, and `make package` on Plasma 6.
3. Inspect the generated package and checksums in `dist/`.
4. Install the generated `.plasmoid` in a clean test profile and verify the panel icon, popup, configuration dialog, theme switching, and upgrade behavior.
5. Commit the release, create an annotated `v<version>` tag, and push both the branch and tag.

## GitHub release

Create a release from the version tag. Attach the `.plasmoid`, source archive, and `SHA256SUMS` generated by `make package`. Use the matching changelog section as the release notes.

## KDE Store and Plasma's widget browser

Create a Plasma 6 Widget product on the KDE Store with the package name **zRAM Monitor**, category **System Information**, and this repository as its homepage and source-code link. Upload the `.plasmoid` as the downloadable release, add both light and dark screenshots, declare GPL-3.0-or-later, and paste the current changelog entry.

KDE's “Get New Widgets” interface consumes the KDE Store catalog, so a correctly categorized and published KDE Store product is the normal route into Plasma's widget browser. Verify discovery and installation from a separate Plasma profile after publication.
